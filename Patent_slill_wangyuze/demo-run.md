## 2. 检索词矩阵草案

### 靶点词

`激酶 X`、`kinase X`、`X kinase`、靶点基因符号、蛋白全称、旧符号、激酶家族名、结合位点、抑制机制。

### 疾病词

`复发难治实体瘤`、`relapsed refractory solid tumor`、`advanced solid tumor`、`treatment-resistant solid tumor`、具体器官/肿瘤类型、耐药、晚期、治疗线次和生物标志物。

### 技术形态词

`small molecule`、`inhibitor`、`compound`、`salt`、`polymorph`、`prodrug`、`formulation`、`crystal`、`process`、`combination`、`regimen`、`method of treatment`、`biomarker`。

### 当前缺口

在获得真实分子名称或结构前，不应把任何具体化合物专利归入“核心命中”。

## 3. 计划检索路径

1. 用真实分子名/代号 + 靶点 + 适应症做标题、摘要和权利要求精确检索；
2. 用分子同义词 + 机制词 + 技术形态词提高召回率；
3. 对高相关命中扩展 IPC/CPC、申请人、发明人、引用/被引用文献；
4. 从 WO/PCT 文献扩展 CN、US、EP 及国家阶段；
5. 按 DOCDB simple family 去重，按 INPADOC extended family 标记技术关联；
6. 回到目标法域官方登记簿核验法律状态。

## 7. 技术路线图骨架

`疾病需求 → 激酶 X 机制 → 结构系列 → 先导化合物 → 候选物 → 选择性/药代/安全性 → 制剂与给药 → 联合治疗/生物标志物 → 临床阶段`

真实运行时，为每个节点绑定代表专利族、优先权日期、关键权利要求、实施例、研发证据和置信度；同时分开呈现“专利保护路线”和“研发事实路线”。

## 8. 风险与创新空间

本次不输出具体风险等级。真实运行时应检查：

- 候选分子是否接近核心化合物或 Markush 范围；
- 盐型、晶型、前药、制剂是否另有独立保护；
- 具体肿瘤、患者分层、联合用药、剂量和疗程是否存在用途/方案族；
- 目标法域是否存在授权、审查中、分案或继续申请；
- 是否形成“化合物—制剂—用途—联合—剂量”的多层布局。

创新空间只能表达为“假设”，每项都需要证据、反例、后续实验/检索和律师复核动作。
