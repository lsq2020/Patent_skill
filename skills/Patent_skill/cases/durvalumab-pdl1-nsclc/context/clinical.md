# 临床/研发上下文（公开专利语境）

这是可选的研发情报层，不替代临床注册、监管标签或专利法律状态。

- 早期 B7-H1/PD-L1 抗体平台：核心问题是阻断 PD-L1 与 PD-1/CD80 的相互作用，并通过 Fc 工程降低不希望的效应功能；可由原始抗体家族说明书交叉核对。
- NSCLC 方案扩展：公开专利材料覆盖 PD-L1/CTLA-4 联合、局部晚期不可切除 III 期同步放化疗，以及可切除 NSCLC 的围手术期铂类化疗联合方案。
- 需要补检：PACIFIC、AEGEAN 等公开临床项目的注册号、入组人群、给药方案和结果应从 ClinicalTrials.gov、监管文件或公司正式披露补齐，不应仅由专利说明书推断。
